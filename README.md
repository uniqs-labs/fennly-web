# fennly-web
Fennly public site (landing + privacy policy). Static, deploys to Vercel → fennly.app. UNIQS vGmbH.

Guides (Ratgeber) are Markdown files in `content/<lang>/<type>/`, built by the UNIQS content engine (`.content-engine/`, `content.config.json`; see uniqs-labs/content-engine). `npm install && npm run build` writes the site to `dist/`, which Vercel serves. robots.txt and sitemap.xml are generated by the build.
